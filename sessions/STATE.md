## Известные проблемы

- **Приложение ни разу не открывалось в браузере.** Проверен только факт раздачи
  файла по HTTP. Ни один пользовательский сценарий не проходился — утверждать,
  что приложение работает, оснований нет.
- **Ни один перенесённый скилл ни разу не вызывался**, включая `frontend-design`.
  Что они работают в этом проекте — предположение.
- **В скиллах Superpowers есть битые перекрёстные ссылки** на `executing-plans`
  и `finishing-a-development-branch` — их не переносили. Наткнувшись на такую,
  агент останавливается и спрашивает.
- **Вердикт по безопасности Superpowers неполон, и это записано честно:**
  маркетплейс не проверялся; 13 файлов скиллов целиком не читались; `server.cjs`
  прочитан выборочно; история коммитов не анализировалась.
- **Скилл `frontend-design` взят только файлом `SKILL.md`.** Лицензия лежит
  в корне чужого репозитория, отдельного `LICENSE.txt` рядом со скиллом нет,
  хотя его фронтматтер на такой файл ссылается.
- **Установить плагины из сессии невозможно** — `/plugin` открывает интерактивную
  панель, `claude` как CLI в PATH отсутствует. Обходимся переносом файлов.
- **Дефект в приложении не исправлен:** `save()` глотает исключение пустым `catch`,
  переполнение квоты `localStorage` приводит к тихой потере данных. Как чинить —
  описано в `SPEC.md`.
- **Приложение — один файл на 766 строк**, и это главное ограничение для параллельной
  работы. Снимается разделением на три файла, которое пока не сделано.
- **После установки Node в уже открытой сессии PowerShell `node --version`
  не работает** — `PATH` процесса не обновляется. Нужен новый терминал
  или явное перечитывание `PATH`.
