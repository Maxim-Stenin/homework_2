# Автотесты «Мои финансы» — смоук-набор

Шаг 7 цикла QA (`workflows/qa-cycle.md`). Набор отвечает на один вопрос:
**не сломалось ли остальное** после добавления фичи. Полную приёмку он
не заменяет — она в `TEST-PLAN.md`, 67 проверок.

## Запуск

Нужен только Node.js 24 и установленный Chrome. Из корня `result/`:

```bash
node tests/run.mjs
```

Раннер сам поднимает стенд на порту **8086**, сам его останавливает и возвращает
код `0` при зелёном прогоне, `1` при падении, `2` если прогон не состоялся
(стенд не поднялся, Chrome не найден).

Ключи:

| Ключ | Что делает |
|---|---|
| `--headed` | видимое окно браузера вместо `--headless=new` |
| `--base-url=http://127.0.0.1:8080` | прогон на уже поднятом стенде, свой не поднимать |
| `--port=8087` | другой порт для собственного стенда |
| `--only=ПР-F,ПР-T` | подмножество проверок по началу идентификатора |

Порт занят — раннер падает с объяснением и **не подбирает соседний молча**
(правило из `AGENTS.md`).

## Чем прогоняется

Chrome по CDP из Node 24: встроенный `WebSocket`, `fetch`, ноль зависимостей.
`node_modules` в проекте не появляется. Решение человека (сессия 8) — из двух
вариантов, `@playwright/test` с установкой и CDP без установок, выбран второй.

Настоящие, а не подменённые: `window.confirm` (`Page.javascriptDialogOpening`),
скачивание файла (`Browser.setDownloadBehavior`), импорт файла
(`DOM.setFileInputFiles`), системная тема (`Emulation.setEmulatedMedia`),
ширина экрана (`Emulation.setDeviceMetricsOverride`).

## Правило набора

Тесты написаны **со стороны пользователя**: только DOM и то, что доступно
снаружи. Исходный код приложения не читается, функции не подменяются,
внутренние структуры не трогаются. Опорой служат `id` из §1.5 `TEST-PLAN.md` —
они зафиксированы правилами проекта и не переименовываются.

Следствия, которые видно в коде тестов:

- **видимость** проверяется по вычисленному `display` и коробке
  `getBoundingClientRect()`, а не по атрибуту `hidden` (находка Н-15);
- **опции списков** выбираются по видимой подписи, а не по внутреннему `value`;
- **суммы** читаются из `#sumIncome` / `#sumExpense` / `#sumBalance` как текст,
  неразрывные пробелы `U+00A0` приводятся к обычным.

## Чего набор намеренно не покрывает

Это не забытое, а отложенное — с причиной:

- **контраст и цвет** (ПР-T-06, ПР-T-07) — замер вычисленных цветов автоматизируем,
  но вердикт «розовый или нет» на границе оттенков остаётся человеческим;
- **анимации** (ПР-D-04) — длительность снимается из стилей, а «приятность» нет;
- **клавиатурный путь целиком** (ПР-D-03) — 20 остановок обхода, отдельная работа
  на `Input.dispatchKeyEvent`; в смоук не помещается по времени;
- **приватный режим** (ПР-S-03) — требует подмены `localStorage` **до** скриптов
  страницы и отдельного профиля браузера;
- **раскладка 1280 px по существу** (ПР-D-02) — «блоки сужены, кнопка справа»
  проверяется глазами, а не координатами.

Эти пункты остаются за ручным прогоном по `TEST-PLAN.md`.

## Файлы

| Файл | Что внутри |
|---|---|
| `run.mjs` | стенд, браузер, контекст на каждый тест, отчёт, код возврата |
| `smoke.mjs` | сами проверки |
| `lib/cdp.mjs` | клиент CDP: запуск Chrome, команды, события, диалоги, файлы |
| `lib/app.mjs` | обёртка над экраном приложения: фикстуры, чтение, действия |
| `lib/runner.mjs` | регистрация проверок, ассерты, печать отчёта |

Фикстуры Ф1 и Ф2 — из §1.3 `TEST-PLAN.md`, дословно. Временные файлы прогона
(скачанные CSV, профиль браузера) живут в системном каталоге и удаляются
по окончании; в репозиторий не попадает ничего.
