# Повторяемые процедуры

Обязательный пункт 3 задания. Здесь лежат workflow — записанные последовательности
шагов, которые запускаются повторно и дают предсказуемый результат.

| Файл | Процедура | Покрывает |
|---|---|---|
| [`qa-cycle.md`](qa-cycle.md) | цикл QA: получение документации → анализ → составление тестовых проверок | шаги 1–3 из семи |

Полный цикл QA — семь шагов: получение документации, анализ документации,
составление тестовых проверок, тестовый прогон, передача багов в разработку,
ретест, написание автотестов. В `qa-cycle.md` описаны **шаги 1–3 включительно**;
шаги 4–7 добавляются туда же по мере прохождения — процедура пишется по факту
её выполнения, а не авансом.
