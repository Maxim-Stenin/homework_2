# CLAUDE.md

Точка входа для Claude Code. Все правила проекта лежат в `AGENTS.md` —
он подключается строкой ниже и читается автоматически при старте сессии.

@AGENTS.md

---

## Почему два файла, а не один

`AGENTS.md` — межвендорная конвенция: этот файл читают Codex, Cursor, Copilot,
Gemini CLI и ещё около двух десятков инструментов. `CLAUDE.md` понимает только
Claude Code, зато он умеет импортировать другие файлы через `@`.

Отсюда схема: содержательные правила живут в одном месте — в `AGENTS.md`,
а `CLAUDE.md` остаётся тонкой прослойкой, которая на него ссылается.
Сменили инструмент — правила поехали с вами, переписывать ничего не нужно.

**Дорабатывайте `AGENTS.md`, а не этот файл.** Сюда добавляют только то,
что относится к Claude Code и ни к чему больше.

## Проверка, что связка работает

Запустите агента в папке проекта и спросите:

```
Какие правила проекта ты сейчас видишь? Перечисли коротко и скажи,
из какого файла каждое взял.
```

Агент должен назвать правила из `AGENTS.md`. Если он их не видит — проверьте,
что оба файла лежат в корне проекта, а строка `@AGENTS.md` не потерялась
при редактировании. Работаете не в Claude Code — просто откройте `AGENTS.md`
и убедитесь, что ваш инструмент его читает.
